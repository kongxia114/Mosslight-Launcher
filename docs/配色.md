# 配色（从启动器里导出的原始 token）

> 值来自 `Mosslight.Core/Theme/ThemeData.g.cs`（48 个 token × 2 套主题），
> 那是 `core/theme.py` 生成的 —— 跟运行中的界面上看到的一模一样。
> 设计网站可以直接用同目录的 `palette.css`（CSS 变量）或 `palette.json`（设计 token）。

## 一套主题的取色逻辑

```
bg_window   最外层（窗口边缘）
bg_sidebar  左侧栏
bg_page     页面底色          ← 卡片浮在它上面
bg_card     卡片
bg_elevated 卡片里的「再浮一层」（输入框容器 / 选中行）
bg_control  控件底（输入框 / 下拉）
bg_hover    悬停   bg_pressed 按下   bg_disabled 禁用

border → border_control → border_hover → border_selected（由弱到强）
text → text_secondary → text_dim → text_faint → text_disabled（由强到弱）
```

**强调色是一整族**：`accent` 是最鲜的那颗（图标 / 链接 / 选中文字），
`accent_fill` 是**填充**用的那颗（主按钮底色，比 accent 暗一档，白字压得住），
再往上还有 hover / pressed / disabled 三档，以及淡底 `accent_bg` + 描边 `accent_border`。
