# 安装与运行

## 下载什么

只有**一个包**，约 **1.4 MB**：`Mosslight-2.0-<tag>-win64.zip`
（[Releases](https://github.com/kongxia114/Mosslight-Launcher-2/releases) 页底 Assets 里）。

解压出来只有一个 `Mosslight.exe`，双击就能跑。语言数据（5 种）编在 exe 里，**不需要**带别的文件。

| 大小 | 运行前提 |
|---|---|
| zip 约 1.4 MB / exe 2.0 MB | 机器上要有 **.NET 10 桌面运行时（x64）** |

**为什么要装运行时**：这是框架依赖发布（`--self-contained false`），好处是更新一次只下 1.4 MB。
装一次运行时，以后每个版本都只下 1.4 MB。

## 第一次运行

1. 装 **.NET Desktop Runtime 10.0（x64）** —— <https://dotnet.microsoft.com/download/dotnet/10.0>
   ⚠️ 不是 SDK，也不是 ASP.NET Core Runtime。
2. 解压 zip 到任意目录（**建议不要在 `C:\Program Files` 下**，自动更新要写同目录文件）。
3. 双击 `Mosslight.exe`。第一次启动会做三件事：
   - 在 exe 旁边建 `Mosslight\`（配置目录）、`Logs\`、`skins\`；
   - 把旧版 `%APPDATA%\Mosslight\config.json` **复制**过来（旧文件保留，不删）；
   - 写入窗口大小 / 语言等跟机器绑定的状态到注册表 `HKCU\Software\Mosslight`。

## 配置放哪

| 内容 | 位置 |
|---|---|
| 设置（主题、强调色、内存、下载线程、Java 路径…） | `<启动器目录>\Mosslight\config.json` |
| 账户（含第三方 token） | `<启动器目录>\Mosslight\accounts.json` |
| 收藏夹 / 按版本覆盖的参数 | `<启动器目录>\Mosslight\favorites.json` / `versions.json` |
| 日志 | `<启动器目录>\Logs\launcher.log`、`game.log`、`auth.log`、`apply_update.log` |
| 自定义皮肤 | `<启动器目录>\Mosslight\skins\<档案名>.png` |
| 窗口大小 / 界面语言 / 上次运行版本 | 注册表 `HKCU\Software\Mosslight` |

**整个文件夹拷走就是完整迁移**（配置跟着 exe 走）。
想完全隔离（截图、试配色）：把 exe 拷到一个空目录再跑，配置就落在那个目录的 `Mosslight\` 里。

> 如果 exe 所在目录不可写（比如装在 `Program Files`），配置会退到 `%APPDATA%\Mosslight\`，日志里会写一行说明。

## 自动更新怎么工作

1. 启动后**后台**查一次 GitHub Release（10 秒超时，失败只记日志）；
2. 有新版本 → 弹窗显示更新内容（Markdown 渲染）；
3. 点「立即更新」→ 下载 zip → **SHA256 校验** → 解压到 `Temp\NewVersionFiles\`；
4. 写 `Temp\pending_update.json`（版本 + 更新日志）+ 生成 `apply.bat`（静默执行）；
5. 启动器退出 → bat 等 3 秒 → 覆盖 exe → 用**你当前的文件名**重启（改过名也认）；
6. 新版本第一次启动读 `pending_update.json`，弹「更新成功」。

细节和失败排查：[常见问题 · 更新](常见问题.md#更新失败了)。

## 手动装 / 换版本

直接把 zip 里的 `Mosslight.exe` 覆盖到原目录即可（配置、账户、日志都还在）。
换之前**先退出启动器**，否则文件被占用。

## 界面语言

设置 → 外观 → 语言，5 种（简体中文 / 繁體中文 / English / 日本語 / Русский）。
切换即时生效；语言记在注册表里，换版本不丢。
