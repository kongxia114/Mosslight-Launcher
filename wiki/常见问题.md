# 常见问题

## 双击没反应 / 闪一下就没了

1. 先看 `<启动器目录>\Logs\launcher.log` 的最后几行——启动期的错误都写在那儿。
2. 大概率是缺 **.NET 10 桌面运行时（x64）**。Windows 会弹一个带官方下载指引的框；也可以直接装：
   <https://dotnet.microsoft.com/download/dotnet/10.0>（选 **Desktop Runtime**，不是 SDK）。
3. 如果日志里有 `UnauthorizedAccessException`：exe 可能装在 `Program Files` 这类不可写目录，
   配置写不进去。换个目录（比如 `D:\Games\Mosslight`）。

## 杀毒软件报毒 / 文件被删

单个未签名的 exe 被启发式引擎拦很常见（我们也遇到过 `authlib-injector.jar` 下载后被删）。

- 把启动器目录加入白名单；
- 更新时如果日志写「更新包刚下好就被删掉了」，说明是实时防护介入，加白名单再试；
- 本项目只从 GitHub Releases 下载资产，并且**每个包都校验 SHA256**。

## 更新失败了

| 现象 | 原因 / 处理 |
|---|---|
| 「更新包不见了！按理说它应该在 …」 | 极少数情况：杀软在下载完成瞬间删文件。把启动器目录加白名单重试 |
| 「下载失败，请检查网络」 | 网络不通或代理拦了 GitHub。手动下载 zip 覆盖 exe 即可 |
| 「文件被占用或权限不足，请手动下载」 | 替换脚本 `move` 失败：启动器还在跑、或有进程锁着 exe。退出后手动覆盖 |
| 「自动更新失败」弹窗 | 上次 `apply.bat` 失败，详情在 `Logs\apply_update.log`。手动覆盖一次即可恢复 |
| 更新完版本号没变 | 检查 `Logs\update.log` 与 `Logs\apply_update.log`；手动覆盖最稳 |

更新日志位置：`Logs\launcher.log`（检查/下载/校验）、`Logs\update.log` 与 `Logs\apply_update.log`（替换脚本）。

## 第三方账户登录不上

- **此账号开启了两步验证**：密码登录会被服务器拒绝，界面会提示「请切换到『网页授权』登录」；
- **「还没有配置 LittleSkin 应用」**：这个构建没注入 client id / secret（自己从源码构建时常见）。
  设环境变量 `MOSSLIGHT_LITTLESKIN_CLIENT_ID` / `_SECRET` 再启动，或看 [第三方登录](第三方登录.md)；
- **角色列表为空**：先去皮肤站网站创建一个角色，再回启动器重新登录。

## 游戏启动失败

1. 看 `Logs\game.log`（游戏原始输出）和状态行提示；
2. 常见原因：Java 版本不对（1.20.1 要 17、1.16.5 要 8）、游戏文件缺失（版本管理 → 补全文件）、
   整合包没装完；
3. `Logs\launcher.log` 里会记「没找到 Java N，请先安装」。

## 头像不对 / 没有头像

- 第三方账户：登录后会自动拉皮肤，存到 `Mosslight\skins\<档案名>.png`，**6 小时**自动刷新一次；
- 账户页底部有「刷新头像」按钮，可立刻重拉；
- 离线账户：按 UUID 从 9 张默认皮肤里挑（跟游戏里一致）。想指定：把皮肤放到 `Mosslight\skins\<档案名>.png`。

## 启动器把游戏窗口挡住了 / 想边玩边看日志

设置里可以开「启动游戏后关闭启动器」「启动游戏后自动打开日志窗口」。
日志窗口支持分级过滤、噪音过滤、导出。

## 配置能跟 1.0.0 共用吗

键名一样，位置不同：1.0.0 在 `%APPDATA%\Mosslight\`，2.0 在 `<启动器目录>\Mosslight\`，
**第一次启动自动复制**（旧文件保留）。不要同时开两个版本改设置——最后保存的那份赢。

## 正版（微软）登录什么时候有

短期不会有。Azure 应用注册免费，但 Minecraft Services 会返回 `403 Invalid app registration`，
`XboxLive.signin` 需要加入 Xbox / ID@Xbox 开发者计划。界面上如实禁用了那一项。
