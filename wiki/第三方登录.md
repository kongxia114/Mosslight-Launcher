# 第三方登录（LittleSkin / 自建皮肤站）

支持两条路，**都在「新建档案 → 第三方验证」里**：

| 方式 | 适用 | 说明 |
|---|---|---|
| 账号密码 | LittleSkin + 任何标准 Yggdrasil 服务器 | 直连 `{服务器}/authserver/authenticate` |
| 网页授权（OAuth 2.0 授权码） | 仅 LittleSkin | 浏览器登录 → 本机回调 → 换 token |

网页授权只对 LittleSkin 开放：**自定义服务器**那一栏的「网页授权」标签是灰的，
因为大多数自建皮肤站没有实现 OAuth。

## 账号密码登录

1. 新建档案 → 第三方验证；
2. 认证服务器：默认 `https://littleskin.cn/api/yggdrasil`，或选「自定义」填自己的地址
   （一般以 `/api/yggdrasil` 结尾）；
3. 填**用户名/邮箱**和**密码**，点「登录」。

登录成功后：

- 角色自动写进 `accounts.json`，包括 `access_token` / `client_token`；
- 开了**两步验证**的账号会被服务器拒绝，界面提示「请切换到『网页授权』登录」；
- 密码不落盘，只在这一次请求里用。

## 网页授权（LittleSkin）

1. 服务器保持 `LittleSkin`；
2. 切到「网页授权」标签 → 点「使用 LittleSkin 网页授权登录」；
3. 浏览器打开 LittleSkin 授权页 → 同意 → 自动回到启动器（本机 `127.0.0.1:25566` 回调）；
4. 读到角色后关闭窗口。

> 需要构建时注入了 LittleSkin 应用的 client id / secret。官方 Release 已经注入；
> 自己从源码构建时没配的话，按钮会灰掉并提示「还没有配置 LittleSkin 应用」。

自己配的办法（任选其一）：

```powershell
# 1) 环境变量（本地调试最省事）
$env:MOSSLIGHT_LITTLESKIN_CLIENT_ID     = '<client id>'
$env:MOSSLIGHT_LITTLESKIN_CLIENT_SECRET = '<client secret>'

# 2) 生成编译期凭据（CI 用的就是这条）
pwsh tools\make-build-secrets.ps1 -Entries @(
    "littleskin.client_id=<client id>",
    "littleskin.client_secret=<client secret>")
```

## 多角色

一个 LittleSkin 账号可以有多个角色。登录时如果读到多个，会弹「选择角色」让你定一个默认；
之后在**账户页**那一行的下拉框里随时切换，切换会立刻存盘，启动游戏用的就是选中的那个角色。

## 皮肤头像

登录成功后启动器会：

1. 请求 `{服务器}/sessionserver/session/minecraft/profile/{uuid}` 拿到 `textures.SKIN.url`；
2. 下载皮肤，存到 `Mosslight\skins\<档案名>.png`；
3. 显示时从皮肤里抠 `(8,8)` 那块脸，**帽子层 `(40,8)` 一起叠**（不然 Ari 的头发、Noor 的头巾会丢）。

本地皮肤超过 **6 小时**会在打开账户页时自动刷新；也可以点账户页底部「刷新头像」立刻重拉。

## 启动游戏时会自动做什么

1. **token 续期**：距离过期不到 24 小时就续（OAuth 走 `/oauth/token`，Yggdrasil 走 `/authserver/refresh`），续完写回 `accounts.json`；
2. **检查 `Libraries\authlib-injector.jar`**：没有就**自动下载**（约 200 KB，官方 v1.2.8 release）；
3. **拼 JVM 参数**：

   ```
   -javaagent:<启动器目录>\Libraries\authlib-injector.jar={认证服务器}
   -Dminecraft.api.auth.host={认证服务器}
   -Dminecraft.api.session.host={认证服务器}
   -Dminecraft.api.profile.host={认证服务器}
   ```

4. **`--uuid` 用去连字符的小写 UUID**，`--accessToken` / `--username` 取当前角色。

> 缺 jar 且下载失败时会拦下启动并提示「下载失败，请检查网络，或手动下载放入 Libraries 文件夹」。

## 自定义服务器支持到什么程度

- ✅ 账号密码登录（标准 Yggdrasil `authenticate`）
- ✅ 启动时注入 authlib-injector（皮肤 / 会话才认这个账号）
- ⛔ 网页授权（大多数自建站没有 OAuth）
- ⛔ 密码修改 / 注册（请到皮肤站网站操作）

## 安全说明

- 第三方 token 存在 `accounts.json`（明文，跟官方启动器一样）；不想要就删掉档案；
- 桌面端二进制里的 client secret **一定能被提取**，它只是"防止路人随便调"的门槛，不是账号密码级的安全；
- 密码只在登录那一次请求里出现，不写文件、不进日志。
